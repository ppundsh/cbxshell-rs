# 文件、設計檔、語法預覽與隨附工具 (Documents, Syntax & Tools)

除壓縮檔與影音媒體外，CBX Shell 亦支援 Office 文件、Photoshop 設計檔、純文字與語法上色預覽，並隨附 Windows 11 控制中心、安裝精靈與命令列工具。

---

## 1. 文件、設計檔與純文字預覽（「其他」類別）

- **Office 文件（`.docx`, `.doc`, `.xlsx`, `.xls`）**：
  - `.docx` / `.xlsx`：讀取 OOXML 內嵌預覽縮圖或繪製文件／試算表摘要預覽卡片。
  - `.doc`：擷取檔案前 256 KiB 中可讀的文字片段作為摘要卡片（非完整 OLE2 解析）。
  - `.xls`：顯示 Excel 樣式卡片，不解析內容。
- **Adobe Photoshop（`.psd`）**：
  - 直接讀取 PSD 檔頭中的合成影像或內嵌縮圖資源，無需安裝 Photoshop 即可顯示縮圖。
- **純文字與 Markdown（`.txt`, `.md`）**：
  - 以高解析度文字排版繪製縮圖（讀取前 16 KiB，最多 24 行）。
  - 支援「自訂純文字縮圖關聯副檔名」（預設為空，可於控制中心自行新增）。
- **BitTorrent 種子檔案（`.torrent`）**：
  - 解析 Bencode `info` 中繼資料並繪製種子內的資料夾與檔案清單，右下角疊加系統預設關聯程式圖示；檔名會先移除雙向覆蓋與零寬等偽裝字元。
- **預覽內容隱私遮罩**：純文字、語法上色、Word 與 Excel 預覽在繪製前會遮罩私鑰區塊、密碼／權杖等 `key = value` 設定值、網址內嵌密碼與常見權杖格式，避免機密內容被寫入 Windows 縮圖快取（詳見 [`security.zh-TW.md` §7](./security.zh-TW.md)）。

---

## 2. 常見語法與純文字上色預覽

系統提供 20 種常見開發與設定檔格式的語法上色縮圖（預設關閉，可於控制中心獨立卡片個別勾選、全選或套用）：

- **資料與標記語言**：`.json`, `.csv`, `.html`, `.htm`, `.xml`, `.yaml`, `.yml`, `.toml`, `.ini`, `.log`
- **腳本與程式碼**：`.ps1`, `.cmd`, `.bat`, `.sh`, `.sql`, `.py`, `.js`, `.tsx`, `.css`, `.rs`

啟用後，關鍵字、字串、註解、數字與標點符號將自動進行語法上色顯示。

## 3. 縮圖外框樣式

所有媒體類別皆可分別選擇 6 種外框樣式：
1. **無外框（No Frame）**：保留原始縮圖影像。
2. **無外框圓弧（Round Only）**：僅將縮圖四個邊角進行圓弧裁切，不加任何外框或白邊。
3. **底片卷軸（Filmstrip）**：兩側齒孔與圓角外框。
4. **柔和投影（Drop Shadow）**：帶圓角與柔和陰影之懸浮效果。
5. **相框風格（Photo Frame）**：具備光影漸變與陰影層次之相框外框。
6. **書籍封面（Book Cover）**：模擬書脊折線與封面立體感。

## 4. 隨附應用程式與命令列工具

- **控制中心（`cbx-manager.exe`）**：
  - 自動跟隨 Windows 系統深色／淺色模式與個人化輔色。
  - 左側導覽列採用 Windows 11 Acrylic 磨砂背景（Windows 11 22H2 以上使用系統背景材質，較舊版本改用相容的模糊效果）；關閉「透明效果」或系統不支援時，自動改為不透明底色。
  - 提供各類別副檔名關聯開關、外框樣式預覽、「拖放實驗與縮圖產生」區（拖入檔案：探測與預覽，含純文字解析回退檢測；拖入資料夾：預先產生縮圖）與即時運作監視器。
  - **預先產生縮圖**（進階 › 系統修復與快取管理）：把資料夾拖曳到進階頁，或按「📁 預先產生縮圖」選擇資料夾，會掃描該資料夾與最多 3 層子資料夾中、已關聯到 CBX Shell 的檔案，以多執行緒（CPU 邏輯核心數的一半，2–8 條）呼叫系統縮圖快取 `IThumbnailCache::GetThumbnail`，把結果直接寫進 Windows 的 `thumbcache_*.db`。之後用檔案總管開啟這些資料夾時，縮圖直接由快取提供，不必再逐張呼叫 CBX Shell。可選縮圖尺寸 96／256／768 px（對應中／大／超大圖示）；勾選「強制更新」會重新產生已在快取中的縮圖；網路位置需勾選「包含網路設備」。略過隱藏、系統檔與連結（junction／symlink），單次最多 200,000 個檔案。進度會顯示完成數、新產生／已在快取／失敗數、已用時間與預估剩餘時間（依目前每個檔案的平均耗時估算）。執行完若有失敗項目，標題列會出現「↻ 重試失敗 N 項」，只針對這些檔案以強制更新、一半的執行緒重新產生。Windows 的磁碟清理或儲存空間感知若清除「縮圖」，預先產生的結果也會一併被清掉。
  - **記錄運作日誌**預設關閉（全新安裝也會關閉）。開啟後若未按旁邊的「🔒 鎖定」，10 分鐘後自動停止記錄（按鈕顯示剩餘分鐘；外掛端同樣依時間判斷，管理工具未開啟也會到期）。鎖定後才持續記錄；關閉開關時會一併解除鎖定。自動停止不會清除已記錄的內容，仍可匯出。管理工具會累積保留最近 1,000 筆紀錄（外掛共用記憶體只保留 64 筆），篩選、捲動與匯出都以這份紀錄為準，大量處理時也不會被新紀錄沖掉；其中成功紀錄只保留最近 200 筆，其餘空間留給失敗紀錄，同一檔案之後成功就會移除它先前的失敗紀錄。監視器的「↻ 重作失敗 N」會把紀錄中仍存在的失敗檔案（需完整路徑）重新產生縮圖（需開啟記錄運作日誌）。
- **安裝精靈（發行檔名 `CBXShell-Setup.exe`，原始專案 `cbx-installer`）**：
  - 自動跟隨 Windows 系統深色／淺色模式，整合縮圖類別勾選、系統整合選項、縮圖快取清理，以及 FFmpeg / Everything 元件偵測與官網下載連結。
- **命令列工具（`cbx-cli.exe`）**：
  - 執行 `cbx-cli.exe --help` 可檢視完整指令參數說明，包含 `--selftest`、`--adversarial`、`--test-com <file>`、`--dump-icon <out.ico>`、`--apply-associations` 及單一檔案縮圖匯出與檢測。
