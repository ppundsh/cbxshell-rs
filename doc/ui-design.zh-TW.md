# UI 設計規範 (Fluent UI Design Guidelines)

[English](ui-design.md)

本文件整理 CBX Shell 控制中心（`cbx-manager.exe`）實際採用的視覺與互動規範，數值皆取自 `crates/cbx-manager/src/main.rs` 與 `render_aa.rs`，供其他專案以純 Win32 / GDI（或任何即時繪製框架）重現相同的 Windows 11 Fluent 風格。

> 所有尺寸以 **96 DPI 的設計像素（dp）** 表示，繪製時一律經 `scale_px(px, dpi) = (px × dpi + 48) / 96` 換算；字級以 **pt** 表示，換算為 `-(pt × dpi / 72)` 的 GDI 字高。

---

## 1. 設計原則

1. **系統一致**：跟隨 Windows 深色／淺色模式與個人化輔色，變更時即時重繪（`WM_SETTINGCHANGE`、`WM_DWMCOLORIZATIONCOLORCHANGED`）。
2. **材質分層**：導覽列是半透明的磨砂材質，內容區是不透明的面板，卡片是浮在面板上的實心層，子卡片則略深一階。
3. **互動不位移**：按下時只改變顏色，**文字不移動、邊框不加粗**；回饋以色彩插值與微小縮放（+0.8 px）完成。
4. **短而有方向的動畫**：所有動畫 100–220 ms，以 ease-out 為主，給出「從哪裡來、往哪裡去」的方向感。
5. **反鋸齒**：圓形、膠囊與勾選記號以有號距離場（SDF）計算覆蓋率後繪製，避免 GDI 鋸齒。

### 3.2 輔色（Accent）推導

- 讀取 `HKCU\…\Explorer\Accent\AccentPalette`，取 Light2／Light1／Base／Dark1／Dark2；讀不到時以 `DWM\AccentColor` 推算，再不行則用 `#0078D4`。
- **懸停**：Base 與白色混合 14%；**按下**：Dark1；**Checkbox 懸停**：Base 與黑色混合 16%。
- **深色模式的強調文字**：使用 Light1，若亮度 < 120 改用 Light2；淺色模式使用 Dark1。
- **輔色上的文字**：以 YIQ 亮度判斷，≥ 150 用 `#111111`，否則用白色。
- **輔色淡底**：深色為 `#202020` 混入 Base 22%，淺色為白色混入 Base 12%。

## 4. 材質：磨砂透明與面板

| 層 | 實作 |
| :--- | :--- |
| 導覽列與標題列 | 像素 alpha = 0，直接透出 **Mica**：系統把桌面桌布大幅模糊並上色後，以「相對螢幕固定」的位置放在視窗背後，移動視窗時會看到光暈相對移動。Windows 11 22H2+ 使用 `DWMWA_SYSTEMBACKDROP_TYPE = 2`（DWMSBT_MAINWINDOW）；Windows 11 21H2 使用舊屬性 `DWMWA_MICA_EFFECT`（1029）；Windows 10 1803+ 退回 `SetWindowCompositionAttribute` 的 Acrylic 模糊（色調 `#202020`／`#F3F3F3`，約 80%）。視窗非使用中時，系統會把 Mica 換成實心色。 |
| 失效時 | 「透明效果」關閉或 API 不支援時，所有半透明像素以 `sidebar_bg` 合成為不透明，**絕不出現未模糊的透明窗**。 |
| 內容面板 | `win_bg`，左上角反鋸齒圓角半徑 10，邊緣 1 px `card_border`。有背景材質時，**卡片以外的頁面底色**改為 alpha 0xB4（約 70%）的 `win_bg`，讓同一片 Mica 光暈以更深的色調透出；卡片、文字與控制項維持不透明。實作上在繪製完成後，把面板內「恰好等於不透明 `win_bg`」的像素換成半透明版本。 |
| 導覽列上的文字 | 必須用 `DrawThemeTextEx(DTT_COMPOSITED)` 繪製以保留正確 alpha；GDI `TextOut` 在 alpha = 0 區域會變透明。 |
| 自訂標題列 | 保留 `WS_CAPTION`（Snap、系統選單與工作列標題照常運作），在 `WM_NCCALCSIZE` 把客戶區頂端延伸到視窗頂端；`WM_NCHITTEST` 將頂端邊框回報為 `HTTOP`、標題列其餘區域回報為 `HTCAPTION`；每則訊息先交給 `DwmDefWindowProc`，由 DWM 繪製並處理標題列按鈕。標題列與導覽列共用同一片磨砂背景。 |
| 座標系統 | 介面版面的 y = 0 是標題列下緣：客戶區矩形扣掉標題列高、滑鼠座標減去標題列高、繪製結果在標題列下方輸出，因此既有版面數值不需改動。 |
| 前提 | `DwmExtendFrameIntoClientArea(-1)`、`DWMWA_USE_IMMERSIVE_DARK_MODE` 跟隨主題。 |

## 6. 卡片與子卡片

- **卡片**：`card_bg` 填色 + 1 px `card_border`，卡片之間不使用陰影，只靠色階分層。
- **子卡片**：在卡片內以 `sub_card_bg` + `sub_card_border` 表示次層資訊，例如預覽區與說明框。
- **可摺疊卡片（Expander）**：
  - 標題列高 52，右側依序為 Toggle（40 × 20）、間距 14、箭頭（22 寬，距右 16）。
  - **懸停**：整張卡片向四周各放大 1 px（外框跟著外擴），同時標題列填色在展開時為 `card_bg` → `btn_hover_bg` 的 65%，收合時為 `btn_hover_bg`；展開時只填標題列，以剪裁保留下方直角。
  - **按下**：140 ms cubic ease-out 漸變至 `card_bg` → `btn_hover_bg` 的 35%，標題文字同步由 `text_bright` 淡到 `text_muted`。
  - **展開／收合**：高度以 160–200 ms cubic ease-out 插值，內容依目前高度剪裁。
  - **內容縮排**：展開區的列在卡片左右各再內縮 16（相對卡片內距），標題列不變。
  - **接縫**：展開後（含「即時運作監視器」卡片）標題列與內容之間，以及展開區內不同設定群組之間（例如「影格選取原則」與「平均亮度過濾」），不畫內縮細線，而是以 2 px 的 `win_bg`（頁面底色）橫切整張卡片（連同左右邊框），讓上下看起來是兩張相疊的子卡片。
- **卡片內區段分隔線**：1 px `divider`，左右內縮 16，只用於同一功能內的說明區塊。
- **一張卡片只放一個功能**：不同功能（例如「FFmpeg 元件路徑」與「Everything 搜尋輔助」）必須拆成獨立卡片，以 14 的卡片間距分開，不可在同一張卡片裡用分隔線切開。
- **有子設定的卡片一律是可展開卡片**：子設定（例如「允許讀取網路共用資料夾」「只能讀取區域網路」）只在展開後出現，作為展開區的列，與標題列、彼此之間以接縫分隔；列的縮排、字級、Toggle 位置（距列右緣 52）與「自訂演算法參數」完全相同。不使用卡片內再套一層子卡片底色的作法。標題列可放狀態文字與次要按鈕（如「重新整理」），按鈕的點擊不會觸發展開。

## 7. 導覽列

| 狀態 | 膠囊填色（深色／淺色，白／黑疊加的 alpha） |
| :--- | :--- |
| 一般 | 無 |
| 懸停或選取 | 16 / 11 |
| 選取且懸停 | 10 / 7 |
| 按下 | 140 ms 內由目前值插值到 10 / 7；文字由白（或 `#1A1A1A`）淡到 `#A6A6A6`（或 `#666666`） |

- 項目膠囊左右各內縮 10。切換鈕、導覽項目與語言按鈕共用寬 40 的**圖示欄**：圖示在欄內水平置中，因此展開與收合時所有圖示都對齊同一條垂直線；標籤從圖示欄右側 4 開始，收合時被裁掉。
- **選取指示條**：3 × 20 輔色膠囊，位於膠囊左側 3，直接以反鋸齒方式寫入預乘 alpha 緩衝（不可用 GDI 繪製後再把外框矩形設為不透明，否則周圍半透明像素會變成黑邊）。切換頁面時以 **220 ms cubic ease-out** 移動到新位置，同時進行「擠壓」：高度 × (1 − 0.45 · sin(πp))，到中途縮短 45% 後回到原長。
- 底部語言按鈕：與導覽項目同樣式（透明，懸停／按下／開啟時顯示半透明膠囊），距底 50、高 40、左右內距 10；地球圖示位於圖示欄，其後為語言名稱，右側上箭頭在開啟或按下時上移 2。
- **收合導覽列**：點擊切換鈕後寬度以 200 ms cubic ease-out 在 195 與 60 之間插值，內容區同步左移並重新排版。收合進度超過 0.35 時隱藏狀態文字、超過 0.5 時導覽項只顯示圖示；語言按鈕只剩地球圖示，選單維持 160 寬並向右延伸。切換鈕的懸停／按下樣式與導覽項膠囊相同。

## 8. 控制項

### 8.1 按鈕

| 狀態 | 一般按鈕 | 主要按鈕（輔色） |
| :--- | :--- | :--- |
| 一般 | `btn_bg` / `btn_border` / `text_primary` | Base / Base / 對比文字 |
| 懸停 | `btn_hover_bg` / `btn_hover_border` / `text_bright` | Base +14% 白 |
| 按下 | `sub_card_bg` / `btn_border` / `text_secondary` | Dark1 |
| 停用 | `btn_disabled_bg` / `btn_disabled_border` / `text_disabled`，無互動 | 同左 |

高 28–30、圓角 2.5、10 pt 置中文字。分段選擇鈕（如外框樣式）選取者使用主要按鈕配色，未選取者使用 `sel_unselected_*`。

### 8.2 Checkbox

- 尺寸 16（一般列表）／18（安全規則列）。未勾選時 1.15 px 邊框，勾選時無邊框並填滿輔色。
- 色彩：未勾選深色 `#202024` 底與 `#666666` 框（淺色 `#FBFBFB`／`#8A8A8A`），懸停 `#313136`／`#AAA5A5`（淺色 `#EFEFEF`／`#5C5C5C`）；勾選時填 Base，懸停時填 Base 混黑 16%，勾號用對比文字色。
- **勾選動畫**：勾號折線 (0.23s, 0.52s) → (0.43s, 0.72s) → (0.78s, 0.29s)（s 為方塊邊長），以 **180 ms cubic ease-out** 由左至右描繪；取消勾選立即消失。線寬 max(0.075s, 1.1)。
- **點擊熱區**：方塊加標籤文字整列，上方 2、下方 4 的容差。

### 8.3 Toggle Switch

- 軌道 40 × 20 膠囊；關閉時深色 `#262222`（alpha 0.5）底、`#9E9A9A` 框、`#CECECE` 滑塊（淺色 `#F5F5F5` 底、`#606060` 框與滑塊）；開啟時填輔色，深色滑塊為 `#262222`、淺色滑塊為對比文字色；所有顏色與 alpha 依動畫值插值。
- 滑塊半徑由 5 漸變到 6.5，內距 4；**懸停**時半徑 +0.8 px（以中心為準向外擴張）。
- **動畫**：每 16 ms 以 35% 的差距逼近目標值（指數平滑），差距 < 0.03 時對齊。

### 8.4 Slider

- 軌道高 4（至少 3），已填部分為輔色膠囊。
- 拇指為半徑 9 的圓；深色模式 `#D0D0D0`，懸停或拖曳時 `#E8E8E8` 且半徑 +0.8。
- 懸停熱區為軌道左右各 8、上下各 10。

### 8.5 輸入框

Win11 TextBox 樣式，顏色由卡片底色推算（深色以白、淺色以黑混合）：

| 狀態 | 填色 | 邊框 | 底線 |
| :--- | :--- | :--- | :--- |
| 一般 | 卡片 + 6% 白（淺色：+1.5% 黑） | 卡片 + 8% 白（淺色：+7% 黑） | 1 px，卡片 + 45% 白／黑 |
| 懸停 | 卡片 + 9% 白（淺色：+3.5% 黑） | 同上 | 同上 |
| 輸入中 | 卡片 + 28% 黑（淺色：純白），比卡片更深 | 同上 | **2 px 輔色** |
| 停用 | 卡片 + 3% | 同上 | 與邊框同色 |

- 圓角 4；底線左右內縮 3 以貼合圓角。取得焦點**不會**自動全選或替整段文字上底色：點擊處放置 1 px 游標，按住拖曳即可選取文字；只有**被選取的字元**以輔色底與對比色文字顯示。`Shift+←/→`、`Home`／`End` 調整選取，`Ctrl+A` 全選，`Backspace`／`Delete`、輸入與貼上都會取代目前選取。
- **清除鈕**：只在輸入中且有內容時，出現在框內右側（寬 24，四周內縮 3），圖示為 Segoe Fluent Icons `U+E894`。懸停時有淡底、按下時底色變淡且圖示變暗，**放開時**才動作：欄位有預設值時還原成預設值，否則清空。
- 數值欄只接受數字，`Ctrl+A`、`Ctrl+V`、`Enter`（套用）、`Esc`（取消）。

### 8.6 捲軸

軌道 `scrollbar_track` + `divider` 框；拇指 `scrollbar_thumb`，拖曳時改為 `text_dim`。

## 9. 彈出式選單（Flyout）

- **內容固定**：選單永遠列出完整選項（例如「全部管道｜檔案直讀｜IPC 命中｜搜尋命中｜串流 RPC」），不因目前選取而改變順序或省略。
- **定位（ComboBox 式）**：視窗空間足夠時，選單讓**目前選取項正好疊在觸發按鈕上**，向上下兩側展開；空間不足時整個選單平移到視窗內（上下各留 8），不縮短。
- **展開動畫**：由選取項那一列向上下同時長到完整高度，**105 ms quartic ease-out**（`1 − (1 − p)^4`），內容同步剪裁。
- **觸發時機**：按鈕與選項都在**放開滑鼠**時才生效；按下未放開時只顯示按下狀態，移出後放開則不動作。
- **背景模糊（應用程式內 Acrylic）**：先把選單範圍內的下層像素做三次 box blur（約等於高斯，半徑 12），再疊上半透明色調（深色 `#2C2C2C`／淺色 `#F9F9F9`，alpha 0xD8）與 1 px `btn_border` 邊框，圓角 8；位於導覽列上時，視窗背景材質會再從色調中透出。
- **項目狀態**：高 36（語言）或 28（篩選），內距 4、圓角 4。懸停與已選取項以白／黑半透明膠囊（深色 16、淺色 11）標示，按下時降為 9／6 並把文字換成 `text_secondary`。已選取項左側 2 有 3 × 16 的輔色指示條；**在已選取項上按下**時，指示條於 120 ms 內以 cubic ease-out 收縮 40%，放開後恢復。
- **關閉**：選定項目（放開時）或在選單外按下即關閉，不需要關閉按鈕。

### 9.1 命令列按鈕（Subtle Button）

- 工具列上的觸發按鈕與動作按鈕（監視器的篩選下拉鈕、「清除記錄」）**不畫外框**：平時透明，懸停或選單開啟時填 `btn_hover_bg`，按下時改為 `card_bg` 與 `btn_hover_bg` 之間 55% 的較暗色；背景比點擊列上下各多 2、圓角 8。文字平時 `text_primary`，懸停 `text_bright`，按下 `text_secondary`。
- 不同功能群組之間以 1 px `divider` 的垂直分隔線隔開（例如篩選群組與「清除記錄」之間）。
- 卡片中的一般動作按鈕（如「清理縮圖快取」）仍使用 §8.1 有外框的標準按鈕。

## 10. 對話框（Modal）

- 背景覆蓋黑色，不透明度深色 65%、淺色 35%。
- 卡片最大 620 × 518，距視窗邊緣至少 16，置中；`card_bg`、圓角 4，外加多層偏移陰影（深色系 `#121113`、`#0E0C0E` 等 2–4 px 擴張）。
- 內距左右 22、標題列 18 起始、關閉鈕 26 × 26。

## 11. 動畫總表

| 動畫 | 時長 | 曲線 |
| :--- | :--- | :--- |
| 導覽列收合／展開 | 200 ms | cubic ease-out，寬度插值 |
| 頁面切換（Drill-in） | 200 ms | 內容自下方 14 處以 cubic ease-out 滑入，alpha 線性 0 → 255 |
| 導覽指示條 | 220 ms | cubic ease-out + 45% sin 擠壓 |
| 導覽項目按下 | 140 ms | cubic ease-out |
| 可摺疊卡片按下 | 140 ms | cubic ease-out |
| 可摺疊卡片展開 | 160 ms（排序）、180 ms（安全規則、影片參數）、200 ms（監視器） | cubic ease-out |
| Checkbox 勾選 | 180 ms | cubic ease-out，由左至右描繪 |
| Toggle | 每幀逼近 35% | 指數平滑 |
| 彈出選單 | 105 ms | quartic ease-out，由選取列向上下展開 |
| 按下選單已選取項 | 120 ms | cubic ease-out，指示條收縮 40% |

- **驅動方式**：單一 `WM_TIMER`（16 ms，Checkbox 與拖曳時 10 ms）呼叫 `step_animations()`；沒有任何動畫進行時立即 `KillTimer`，閒置時不耗 CPU。
- **局部重繪**：只有語言選單在動畫時，只重繪導覽列區域。

## 12. 繪製技術要點

1. **雙緩衝**：整個視窗先畫在 32 位元 top-down DIB 上，最後一次 `BitBlt`，避免閃爍（`WM_ERASEBKGND` 回傳 1）。
2. **預乘 alpha**：DIB 像素為預乘 BGRA；半透明元件以 `blend_premul` 疊加，GDI 繪製後再以 `stamp_*` 系列函式把該區 alpha 設為 255。
3. **SDF 反鋸齒**：圓角矩形、圓、膠囊與勾號以「距離 − 半徑」計算 0–1 覆蓋率後混色。
4. **DPI**：Per-Monitor V2，所有尺寸經 `scale_px`。
5. **重入安全**：介面狀態放在 `Mutex` 內並以 `try_lock` 存取，開檔對話框等模態迴圈期間的重入訊息只會排定重繪，不會死鎖。

- [ ] 建立深色／淺色兩組 Token，並從系統讀取輔色推導懸停、按下、對比文字。
- [ ] 以 96 DPI 設計、執行期換算；字型使用 Segoe UI Variable Text 與 Segoe Fluent Icons。
- [ ] 按下狀態只換色、不位移；懸停的放大量不超過 1 px。
- [ ] 所有動畫 ≤ 220 ms，以 ease-out 為主，並在閒置時停止計時器。
- [ ] 彈出選單從觸發點長出、點擊外部即關閉；對話框以暗幕遮罩背景。
